# Portafolio estilo Minecraft

Abre `index.html` en el navegador (doble clic). No necesita servidor ni instalación.
Necesita internet solo para cargar las fuentes de Google Fonts.

## Estructura
portafolio-minecraft/
├── index.html
├── css/style.css
├── js/main.js
├── img/logo.png
├── img/inicio/          (video de fondo y gólem de cobre del inicio)
└── assets/
    ├── iconos/           (tus iconos PNG; ver LEEME.md dentro)
    └── sonidos/          (tus sonidos .ogg/.mp3/.wav; ver LEEME.md dentro)

Si falta un icono o sonido, se usa el que viene integrado.

## Qué editar
- `js/main.js`, bloque CONFIG: correo, GitHub y LinkedIn.
- `js/main.js`, lista PROJECTS: tus proyectos.
- `js/main.js`, lista SKILLS: tus habilidades (hasta 27 casillas).
