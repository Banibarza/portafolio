# Iconos

Pon aquí tus iconos en **PNG** (de preferencia cuadrados: 16x16, 32x32 o 64x64).
Se escalan con `pixelated`, así que se ven nítidos aunque sean pequeños.

Si un archivo **no existe**, el portafolio usa el icono pixelado que ya trae dibujado en
`js/main.js`. No se rompe nada: puedes ir agregándolos poco a poco.

| Archivo          | Dónde aparece                                   |
|------------------|-------------------------------------------------|
| `pasto.png`      | Mundos (proyectos) y experiencias               |
| `espada.png`     | Categoría "Backend" en Habilidades              |
| `diamante.png`   | Categoría "Datos" y pantalla final              |
| `cofre.png`      | Categoría "Herramientas"                        |
| `libro.png`      | Categoría "Otras" y avisos de logro             |
| `esmeralda.png`  | Indicador junto al botón "Contacto"             |
| `sonido.png`     | Botón pequeño de sonido (activado)              |
| `silencio.png`   | Botón pequeño de sonido (silenciado)            |

## Iconos propios para una habilidad o proyecto

En `js/main.js` puedes poner `icon: 'laravel'` en una habilidad de `SKILLS`
(o en un proyecto de `PROJECTS`) y agregar aquí `laravel.png`.
